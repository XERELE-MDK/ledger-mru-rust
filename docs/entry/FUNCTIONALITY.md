# Adding an entry — how it works

[← All features](../README.md) · [Code walkthrough](CODE_WALKTHROUGH.md)

"+ New entry" opens a panel. In **Simple** mode you pick expense, income or transfer; in **Accountant** mode, both accounts.

A preview shows the debit and the credit before saving. Deleting offers **Undo**.

The date is typed (`YYYY-MM-DD`): no calendar yet.
