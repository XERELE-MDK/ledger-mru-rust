# Livre vide et démo — fonctionnement

[← Toutes les fonctionnalités](../README.md) · [Parcours du code](CODE_WALKTHROUGH.md)

Au premier lancement, trois mois d'exemples. **Start with an empty book** retire uniquement les écritures de démo ; les vôtres, les comptes et les budgets restent.

Pendant la synchro : le retrait vaut pour tous les appareils ; *Reset* et *Replace* sont refusés, avec l'explication.
