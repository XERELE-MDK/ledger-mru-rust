# Scénario de captures — fonctionnement

[← Toutes les fonctionnalités](../README.md) · [Parcours du code](CODE_WALKTHROUGH.md)

```bash
ledger-desktop --screenshots <dossier>
```

Dessine toute l'interface **sans ouvrir de fenêtre**, sur des données temporaires, en jouant un scénario : saisie juste et fausse, livre vide, soldes de départ, mode sombre, fusion, synchro. Les images sont au format PPM.

C'est aussi un test : une vérification manquée arrête le programme.
