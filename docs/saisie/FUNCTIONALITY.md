# Saisir une écriture — fonctionnement

[← Toutes les fonctionnalités](../README.md) · [Parcours du code](CODE_WALKTHROUGH.md)

« + New entry » ouvre un panneau. En mode **Simple**, on choisit dépense, revenu ou virement ; en mode **Accountant**, les deux comptes.

Un aperçu montre le débit et le crédit avant d'enregistrer. La suppression propose **Undo**.

La date se tape (`AAAA-MM-JJ`) : pas encore de calendrier.
